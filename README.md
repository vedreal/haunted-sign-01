One funny line for the door of a haunted server room (120 characters at most), entered in the [Funniest Sign on a Haunted Server Room Door](https://make.fun/bounty/u-eager-stork-81-9647-funniest-sign-on-a-haunted-ab1d019a) bounty on make.fun. An AI judge reads the lines in pairs and keeps the funnier one each time, so the line that survives every comparison takes the reward.

`main.py` writes ten fresh candidate signs, scores each against the judge's published brief (sign-on-door, laugh from the collision of office IT life and the supernatural, sounds like a sign, fresh specific haunting, tight), and writes the highest-scoring line to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
